# 🎉 Robin's 21st Birthday Card

A tiny, **zero‑build** web app that displays a personalized birthday greeting, confetti animation, and lets the user download the card as a PNG or share it on social media. All you need is a modern browser – just open `index.html`.

---

## Overview

- **Purpose** – A fun, single‑page birthday card that can be hosted on any static site (GitHub Pages, Netlify, etc.).
- **No build step** – All HTML, CSS and JavaScript are plain files. No npm, bundlers or server‑side code required.
- **Responsive & Accessible** – Works on mobile, tablet and desktop, with proper ARIA attributes and keyboard‑friendly controls.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 |
| Styling | CSS3 (custom properties for theming) |
| Behaviour | Vanilla JavaScript (ES6) |
| Animations | Canvas‑based confetti (`assets/confetti.js`) |
| Image export | **html2canvas** CDN (captures the card as a PNG) |
| Icons | Inline SVG (Twitter, Facebook) |

## Feature List

- 🎂 Dynamic greeting (`Happy 21st Birthday, Robin!`).
- 🎨 Theme colours configurable via CSS variables (`--primary-color`, `--secondary-color`, `--background-color`).
- 🎉 Confetti animation that matches the theme colours.
- 📥 **Download** button – saves the current card view as a PNG using `html2canvas`.
- 📤 Social sharing – ready‑to‑go Twitter and Facebook share links.
- 📱 Fully responsive layout with mobile‑first breakpoints.
- ♿ Accessibility – ARIA roles/labels, `aria-live` for the greeting, focusable buttons, and high‑contrast colour defaults.

## Setup Instructions

1. **Clone the repository** (or download the zip):
   ```bash
   git clone https://github.com/your‑username/robin‑birthday‑card.git
   cd robin-birthday-card
   ```
2. **Open the card** – No npm, no build tools:
   - Double‑click `index.html` in your file explorer, **or**
   - Run a simple static server (optional, e.g., `python -m http.server`) and navigate to `http://localhost:8000`.
3. The card loads automatically, shows the greeting, starts the confetti, and the buttons are ready.

## Customising the Greeting

### 1. Edit the constants in **`scripts/main.js**`
The greeting is generated by `setGreeting(name, age)`. In `initCard()` you’ll find:
```js
setGreeting('Robin', 21);
```
Change the name and/or age to suit the recipient.

### 2. (Optional) Use a query‑string API
The script currently does not read URL parameters, but you can easily add support:
```js
function getQueryParam(param) {
  const urlParams = new URLSearchParams(window.location.search);
  return urlParams.get(param);
}

function initCard() {
  const name = getQueryParam('name') || 'Robin';
  const age = parseInt(getQueryParam('age')) || 21;
  setGreeting(name, age);
  // …rest unchanged
}
```
Now you can open the card with `index.html?name=Alex&age=30` to generate a custom greeting on the fly.

## Theme Customisation via CSS Variables

All colours are defined as CSS custom properties in **`styles/style.css`**:
```css
:root {
    --primary-color: #ff6f61;      /* Buttons & main text */
    --secondary-color: #6b5b95;    /* Share buttons */
    --background-color: #f0f0f0;   /* Page background */
}
```
You can:
- **Edit the values** directly in `style.css`.
- **Override them at runtime** with JavaScript (`applyTheme({primary: '#ff4081', ...})`).
- **Add a custom theme** by creating a new object and passing it to `applyTheme` in `initCard()`.

Because the confetti script reads the theme colours (`window.startConfetti({ colors: [...] })`), the whole experience stays colour‑coherent.

## Download & Social Sharing

### Download (PNG)
- The **Download** button calls `handleDownload()` which uses the global `html2canvas` function (loaded from the CDN).
- The card element (`#card`) is rendered to a canvas, turned into a Blob, and saved as `Robin_21_Birthday.png`.
- No server interaction – everything happens client‑side.

### Social Sharing
- **Twitter** – Opens `https://twitter.com/intent/tweet` with pre‑filled text (the greeting) and the page URL.
- **Facebook** – Opens `https://www.facebook.com/sharer/sharer.php` with the same data.
- Links are generated in `setupSocialSharing()` and open in a new tab (`target="_blank"`).

### External CDN Dependency
- **html2canvas** – Loaded via:
  ```html
  <script src="https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js" … defer></script>
  ```
  It is the only external library; all other code is self‑contained.

## Accessibility Notes

- **ARIA** – The main region has `role="region"` and `aria-label`. The greeting uses `aria-live="polite"` so screen readers announce it when it changes.
- **Keyboard navigation** – Buttons are native `<button>`/`<a>` elements, focusable by default.
- **Colour contrast** – Default colours meet WCAG AA contrast ratios. When you customise the theme, keep a contrast ratio of at least 4.5:1 for text against the background.
- **Reduced motion** – If you need to disable the confetti for users with motion sensitivities, comment out the `window.startConfetti` call in `initAnimations()` or add a `prefers-reduced-motion` media query.

## Testing on Different Screen Sizes

The layout is built with a mobile‑first approach:
- **Below 600 px** – Font sizes shrink, the action buttons stack vertically and stretch to full width.
- **600 px – 1200 px** – Standard desktop layout with side‑by‑side buttons.
- **Above 1200 px** – The card still fills the viewport, but you can add larger‑screen tweaks in `styles/style.css` if desired.

To test:
- Resize your browser window manually.
- Use Chrome/Firefox dev tools → **Responsive Design Mode**.
- Verify that the greeting remains readable, buttons stay reachable, and the confetti covers the whole viewport.
